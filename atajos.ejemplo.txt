# Atajos de texto — un atajo por línea, formato:  atajo=texto a insertar
# Copia este archivo como "atajos.txt" (o deja que el programa lo cree) y personalízalo.
#
#   atajo=texto                  → atajo normal (Tab/Enter para insertar)
#   atajo!=texto                 → expansión instantánea (sin Tab)
#   atajo[5|10|15]=...{1}...     → grupo desglosable: //atajo abre un submenú
#   atajo[a:Et A|b:Et B][5|10]=  → dos niveles de desglose, {1} y {2}
#
# Variables: {fecha} {hora} {dia} {fecha_larga} {cursor} — \n = salto de línea
